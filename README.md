# Nika Mise

Caja, stock y vencimientos para kioscos, almacenes y comercios.

- `/` → app con cuenta real (inicio de sesión, datos en Supabase, funciona sin internet).
- `/?demo` → demo con datos de ejemplo, sin cuenta.

Este repositorio tiene la versión ya armada (sitio estático). Vercel la publica en cada cambio de `main`.
